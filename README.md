# AK AI V1 Complete

Mobile-first Next.js starter for AK AI Video Prompt Intelligence.

Run:
npm install
npm run dev

Optional real AI:
copy .env.example to .env.local and add OPENAI_API_KEY.
Never expose secrets with NEXT_PUBLIC_ and never commit .env.local.

V1 includes UI, server API routes, demo prompt engine, optional server-side OpenAI adapter, targeted improvement V2, model selector, prompt sections and copy/regenerate.
